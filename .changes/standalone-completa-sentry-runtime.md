O build self-host completa e confere os arquivos ESM do runtime Sentry que o rastreamento pode omitir. Diferença de versão, arquivo ou link inesperado faz o build falhar em vez de publicar um artefato incompleto. O adapter sem standalone preserva seu caminho atual. Crédito: @vagnerrm122.
