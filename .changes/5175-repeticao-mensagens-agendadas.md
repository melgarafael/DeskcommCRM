titulo: Mensagens agendadas podem se repetir, com data de término
---

Ao agendar uma mensagem de texto para um contato, quem agenda pode escolher a repetição: diária, semanal, quinzenal, mensal, trimestral, semestral, anual ou a cada N dias. Há data de início e, se quiser, data de término. Cada envio fica registrado no histórico da mensagem, com o desfecho de cada ocorrência, e a lista "Exibir todos" mostra a série inteira. Mensagens de envio único continuam como antes.
