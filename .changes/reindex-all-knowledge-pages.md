Preparing the whole knowledge base again, including after an embedding-provider change, now reads every page of active materials. An API row limit no longer silently leaves later materials out. Materials that need preparation still go first, and a failed listing stops before any errors are cleared or events are queued. Credit: @samirhvbr.
