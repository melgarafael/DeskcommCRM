titulo: Use o Jev como roteador com reserva sob demanda
---
Quem administra agora pode usar o Jev para escolher o agente sem consultar a IA tradicional em cada mensagem. A IA tradicional só é acionada quando o Jev não entrega uma escolha confiável; os modos de comparação continuam disponíveis. O editor do roteador permite ajustar de zero a 16 mensagens anteriores, com oito por padrão para roteadores novos. IA › Execuções › Roteamento mostra custos, tempos, casos e revisão humana. A atualização não exige ação na VPS.
