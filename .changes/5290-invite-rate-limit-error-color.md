titulo: Aviso de erro ao aceitar convite usa a cor de erro
---

Na tela de aceitar convite, o aviso exibido quando há erro (como excesso de tentativas) passa a usar o token de cor de erro (`text-destructive`), igual ao login.

Contribuição de @Yshuro, a partir da issue #5290.
