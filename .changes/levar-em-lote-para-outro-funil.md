titulo: Vários negócios podem ser levados de uma vez para outro funil
---

Na barra que aparece ao selecionar cards no quadro, o menu "Mover para…" ganhou a opção "Outro funil…". Ela leva todos os negócios selecionados (até 50 por vez) para o funil escolhido, com a etapa de entrada opcional — por exemplo, os clientes que fecharam no funil de vendas para o funil de pós-venda. Cada negócio passa pelo mesmo caminho de "Levar para outro funil" de um card só: é recriado no destino com os anexos, e encerra no funil de origem como perdido, com o motivo "Levado para outro funil". A janela mostra o andamento e, no fim, quantos foram levados e quais não foram, com o motivo de cada um (por exemplo, um campo obrigatório do funil de destino). Nenhuma ação é necessária na atualização. Contribuição de @tec7alex.
