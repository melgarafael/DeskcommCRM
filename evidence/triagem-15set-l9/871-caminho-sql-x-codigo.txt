## 2. Mensagens (CÓDIGO): POST /api/v1/webhooks/waha/<token> assinado com HMAC SHA512, como o WAHA faz (script abaixo). Uma imagem (05:24) e um texto (05:36). A ingestão real gravou contato, conversa, mensagens e emitiu media.persist_requested e ai_agent.dispatch_requested.
```js
// Entrega um webhook WAHA assinado (HMAC SHA512) ao app LOCAL, como o WAHA faria.
import { createHmac, randomUUID } from "node:crypto";
const [,, token, kind = "image", from = "5511987650001@c.us", nome = "Paciente Mídia"] = process.argv;
const APP = "http://localhost:3041";
const id = `false_${from}_${randomUUID().replace(/-/g, "").slice(0, 20).toUpperCase()}`;
const payload = kind === "image"
  ? { id, from, fromMe: false, timestamp: Math.floor(Date.now() / 1000), hasMedia: true, body: "",
      notifyName: nome,
      media: { url: `http://127.0.0.1:3999/api/files/clinica-l9/${id}.jpeg`, mimetype: "image/jpeg", filename: null },
      _data: { pushName: nome, message: { imageMessage: {} } } }
  : { id, from, fromMe: false, timestamp: Math.floor(Date.now() / 1000), hasMedia: false, body: kind,
      notifyName: nome, _data: { pushName: nome, message: { conversation: kind } } };
const body = JSON.stringify({ id: `evt_${randomUUID()}`, event: "message", session: "clinica-l9", payload });
const sig = createHmac("sha512", "segredo-do-webhook-qa-l9-local").update(body, "utf8").digest("hex");
const r = await fetch(`${APP}/api/v1/webhooks/waha/${token}`, { method: "POST", headers: { "content-type": "application/json", "x-webhook-hmac": sig }, body });
console.log(r.status, (await r.text()).slice(0, 300), id);
```
